# Demo 测试清单

这份清单用于分享会、答辩或 GitHub 复现检查。建议先启动应用：

```bash
streamlit run app.py
```

## 0. 启动检查

- [ ] 左侧栏显示 AIS 数据加载成功。
- [ ] 左侧栏显示知识库加载成功。
- [ ] 如果未配置 `LLM_API_KEY`，确认离线 AIS 分析功能仍可使用。
- [ ] 如果已配置 `LLM_API_KEY`，确认 LLM 状态显示为已配置。

## 1. RAG 知识问答

- [ ] 进入“海事知识库问答”。
- [ ] 提问：`什么是 VTS？`
- [ ] 检查回答是否引用 VTS / IMO / IALA 相关知识。
- [ ] 展开“查看检索到的知识库片段”，确认有检索来源。

## 2. AIS 船只摘要精确召回

- [ ] 进入“海事知识库问答”或“AIS 轨迹分析 -> 自然语言查询”。
- [ ] 提问：`18330 这艘船的估算总航程是多少？`
- [ ] 预期：系统能召回船 `18330` 的数据，并回答估算总航程约 `495.5` 海里。

## 3. 轨迹地图可视化

- [ ] 进入“AIS 轨迹分析 -> 轨迹地图可视化”。
- [ ] 选择单船模式，选择船 `18330`。
- [ ] 检查地图是否展示轨迹线、起点和终点。
- [ ] 切换多船模式，选择 3 艘船，检查多船轨迹是否显示不同颜色。

## 4. 航速异常检测

- [ ] 进入“AIS 轨迹分析 -> 航速异常检测”。
- [ ] 选择船 `18330`，阈值保持默认或设为 `2.5`。
- [ ] 点击“执行航速异常检测”。
- [ ] 检查是否输出异常明细和地图异常点。

## 5. 锚地 / 停留点聚类

- [ ] 进入“AIS 轨迹分析 -> 锚地聚类”。
- [ ] 低速阈值设为 `0.5`，`eps` 使用默认或 `1.0` 海里。
- [ ] 点击“执行锚地聚类”。
- [ ] 检查是否输出停留簇数量、簇中心、涉及船只数和 CSV 下载按钮。

## 6. 航次识别

- [ ] 进入“AIS 轨迹分析 -> 航次识别”。
- [ ] 选择船 `18330`。
- [ ] 保持默认参数点击“执行航次识别”。
- [ ] 检查是否输出航次数、累计航程、航次表格和单航次地图。

## 7. 地理围栏测试区

- [ ] 进入“AIS 轨迹分析 -> 地理围栏”。
- [ ] 选择 3-5 艘船。
- [ ] 使用“建测试区域”功能，以选中船只活动中心创建一个半径约 `3` 海里的圆形区域。
- [ ] 点击“检测违例”。
- [ ] 检查是否输出违例列表，并在地图上用红色高亮违例轨迹段。

## 8. 月度报告生成

- [ ] 进入“AIS 轨迹分析 -> 月度报告”。
- [ ] 选择 `2020-10`。
- [ ] 勾选“包含航速异常”和“包含围栏检测”。
- [ ] 点击“生成月度报告”。
- [ ] 检查报告预览、月度航程 Top 船只、异常/围栏摘要。
- [ ] 下载 Markdown / Word / PDF，确认文件可打开。

## 9. 航行排行榜

- [ ] 进入“AIS 轨迹分析 -> 航行排行榜”。
- [ ] 分别按估算航程、最高航速、停泊率排序。
- [ ] 检查 Top N 表格和柱状图是否正常刷新。

## 10. 发布前检查

- [ ] 确认 `.env` 没有被提交。
- [ ] 确认 `.venv/`、`.cache/`、`__pycache__/`、日志文件没有被提交。
- [ ] 确认 README 中的截图已替换为真实运行截图或保留明确占位说明。
- [ ] 确认 `dataset/` 体积可接受，且数据用途说明清楚。
